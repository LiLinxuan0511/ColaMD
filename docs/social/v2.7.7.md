# ColaMD v2.7.7 Social Copy

发布方式：正式版。

## Chinese

ColaMD 2.7.7 发布了。这一版给图表换了引擎，并把放不下的图做成能放大的。

**画图的引擎从 Mermaid 换成了 Pele。** 以前为了能画十几种图，安装包要背上三兆多的脚本，渲染还得塞进一个隐藏窗口里跑，图省下那点卡顿。Pele 是 Obsidian 团队做的，吃的是同一份语法，你文件里的图一个字都不用改；包六百多 KB，没有运行时依赖，而且按图种分开加载，文件里没有图就一点代价都没有。整个渲染器从 10M 降到 5.4M。

**放不下的图现在能放大看。** 一张横向铺得很开的图，在窄窗口或者开着大纲面板的时候会被压成一条几十像素高的细线，字糊成一团，因为它只是照容器等比例缩小的。现在这类图角上会出现放大、缩小、还原三个按钮，也可以按住 Ctrl（Windows / Linux）或 Cmd（macOS）滚滚轮；放大之后按住图能拖动平移，双击在原始大小和放大之间切换。本来就放得下的图不出现按钮，单用滚轮还是滚文档，不会被图抢走。

一个提醒：**图的排版和以前不一样了**，节点形状、连线弧度、字号都重新排过。不习惯的话开个 Issue 说一声。

这一版还收了这些：

- 表格点哪一格，光标就落在哪一格（行首带缩进的、没有竖线的表格也认得准），光标进到块里会露出这一块的源码
- 链接里只包一张图（`[![图](a.png)](https://…)`）不会再让整篇正文变成空白
- 公式认得 `\[…\]` 和 `\(…\)`，从 ChatGPT 这类模型粘过来不再是一堆原文
- 行内 HTML 的成对标签只管标签之间的字，不会把整行都染色
- 选中文字不再给全文每个匹配处都描上框
- 代码块里选中文字看得见高亮，导出的 HTML 里不再漏进围栏符号
- 打开文件面板时，正文在可见区域里居中，不再被挤到左边缘

感谢 @wg2038 的表格格子定位与导出围栏修复，@Yesokim 的文件面板动画，以及 @jianlongliu 报告的空白页问题（#157）。

## English

ColaMD 2.7.7 is out. Diagrams have a new engine, and the ones that do not fit can be zoomed.

**Diagrams are drawn by Pele now, not Mermaid.** Mermaid cost three megabytes of JavaScript in the installer so that a dozen diagram types could exist, and it had to be rendered inside a hidden window to keep typing smooth. Pele, from the Obsidian team, reads the same syntax, so nothing in your files changes; its bundle is a bit over 600 KB with no runtime dependencies, loaded per diagram type, so a document without diagrams pays nothing at startup. The renderer drops from 10 MB to 5.4 MB.

**A diagram that does not fit the column can be zoomed.** A wide diagram used to be squeezed into a few dozen pixels of height in a narrow window, or with the outline panel open, because it was simply scaled down to fit; the text became a smear. Such diagrams now show zoom in, zoom out and reset buttons in the corner, and Ctrl (Windows/Linux) or Cmd (macOS) plus the wheel does the same; a zoomed diagram can be dragged to pan and a double click toggles between the original size and the zoom. Diagrams that already fit get no buttons, and a plain wheel still scrolls the document rather than being swallowed by the diagram.

One thing to expect: **diagrams look different from before.** Node shapes, edge curves and type sizes have all been rearranged. If you miss the old look, open an issue and say so.

Also in this release:

- Clicking a table cell puts the cursor in that cell (indented and borderless tables included), and the cursor entering a rendered block reveals that block's source
- A link wrapped around a single image (`[![pic](a.png)](https://…)`) no longer blanks the whole document
- Formulas are recognised with `\[…\]` and `\(…\)`, so text pasted from ChatGPT and friends renders instead of sitting there as raw markup
- A paired inline HTML tag styles only the text between its tags, instead of tinting the whole line
- Selecting text no longer draws a box around every other occurrence of it
- A selection inside a code block is visible again, and exported HTML no longer carries the closing fence
- With the file panel open, the text is centred in the visible area instead of being pushed to the left edge

Thanks to @wg2038 for the table cell targets and the export fence fix, @Yesokim for the file panel animation, and @jianlongliu for the blank document report (#157).
